# Road Map — XenonCLI

План развития проекта. Этапы упорядочены по приоритету; пункты внутри этапа
можно выполнять независимо.

- [x] — готово
- [ ] — предстоит сделать

## Этап 0. Архитектура и инструменты

- [x] Единая модель Xenon ASM (`xenon::Module`, `Function`, `Method`, `Type`,
  `Field`, `Global`) вместо параллельных `Symbol`/`Model*`.
- [x] Единый набор инструкций (`Instruction`) вместо двух наборов опкодов.
- [x] 16-битные операнды: до 65535 констант, строк, локалов и полей.
- [x] Связывание функций, типов и глобалов по именам — модули можно загружать
  в любом порядке, объявления `.hint` не ломают индексы.
- [x] Формат `.module` версии 5: функции, методы, типы, поля, глобалы, атрибуты,
  шаблонные параметры, наследование.
- [x] Ассемблер и дизассемблер текстового Xenon ASM; команды `xenon asm` и
  `xenon disasm`, round-trip «текст ↔ бинарь».
- [x] Подпроекты `xenon.core`, `xenon.env`, `xenon.packer`, `xenon`.
- [x] Configure/build/test-пресеты, `.clang-format`, `.clang-tidy`,
  `.editorconfig`.
- [x] CI (GitHub Actions) на MSVC / GCC / Clang.

## Этап 1. Завершение языка и компилятора

- [x] Строковые литералы → объекты `String` на куче.
- [x] Классы, структуры и перечисления: поля, методы, доступ к членам.
- [x] Шаблоны: шаблонные классы/структуры/функции, явное инстанцирование.
- [x] Глобальные переменные и константы с константными инициализаторами.
- [x] Контроль потока: `for`, `do/while`, `break`, `continue`, `switch`.
- [x] Доп. операторы: `%`, битовые (`& | ^ ~ << >>`), составные присваивания
  (`+=`, `&=`, ...), `++`/`--` (префиксные и постфиксные), тернарный `?:`.
- [x] Вложенные шаблонные аргументы (`Pair<Box<double>>`): `>>` разделяется при
  разборе списка аргументов.
- [x] Квалификаторы `const` (локальные, глобальные, поля, параметры) и проверка
  типов при инициализации, присваивании, вызове и `return`.
- [ ] Реальная обработка `#include` и резолвинг зависимостей `import` на этапе
  компиляции.
- [ ] Фильтрация видимости `export` на уровне VM.
- [ ] Перегрузка функций (сейчас поиск только по имени).
- [ ] Аргументы конструкторов и инициализаторы полей.
- [x] Значения перечислителей (`Enum::Enumerator` и неквалифицированные имена).
- [ ] Строковые глобальные переменные.
- [ ] Шаблонные перечисления/глобальные переменные и вывод типов.

## Этап 2. Байт-код и VM

- [x] Снять ограничение в 256 констант/строк (16-битные операнды).
- [ ] Дальние переходы: использовать `jmpa`/`jifa` при переполнении `i16`.
- [ ] Динамическая диспетчеризация методов (`obj.method()`, `CallMethod`).
- [ ] Доступ к полям и вызовы методов с наследованием.
- [ ] Диагностика: стек-трейсы, номера строк в ошибках рантайма.
- [ ] Исключения и `try/catch` в скриптах.
- [ ] Кэширование разрешённых имён (inline cache) для `call`/`new`/`ldg`.

## Этап 3. Среда выполнения (`xenon.env`)

- [ ] Реальные встроенные методы `String`/`Vector` (длина, concat, push/pop,
  итерация).
- [ ] Связывание нативных классов/методов (не только функций).
- [ ] Доп. классы среды: `Map`, `Array`, обёртки чисел, `Math`.
- [ ] Сборка мусора в `VirtualHeap` (сейчас `std::vector` без GC).

## Этап 4. Упаковщик и CLI

- [ ] Сжатие (DEFLATE) вместо STORE в `.xenon`.
- [ ] Расширенный манифест: зависимости, версия рантайма, параметры запуска.
- [ ] Единые коды завершения (sysexits) для всех команд.
- [ ] Проверка целостности/CRC, опционально подпись архива.
- [ ] Загрузка зависимостей `.xenon`/`.module` по `import`.

## Этап 5. Качество и производительность

- [ ] Больше тестов: крайние случаи парсера, round-trip упаковщика, фазз VM.
- [ ] `cmake --install` + пакетирование релизов (install уже есть).
- [ ] Оптимизации VM: computed goto, inline caching, constant folding.
- [ ] Формальная спецификация языка в `docs/language.md`.
- [ ] Бенчмарки VM и компилятора.
