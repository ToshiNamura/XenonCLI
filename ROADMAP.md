# Road Map — XenonCLI

План улучшений проекта. Этапы упорядочены по приоритету; пункты можно выполнять
независимо внутри этапа.

- [x] — готово
- [ ] — предстоит сделать

## Этап 1. Завершение языка и компилятора

- [ ] Поддержка строк в коде: строковые литералы → объекты `String` на куче (сейчас токенизируются, но отвергаются парсером).
- [ ] Полноценные тела классов/структур/перечислений: поля, методы, конструкторы, доступ к членам (`obj.field`, `Class::method`).
- [ ] Шаблоны: шаблонные классы/структуры/функции/перечисления и глобальные переменные (`SymbolKind::Template` уже есть — нет парсинга и инстанцирования).
- [ ] Глобальные переменные и константы (`SymbolKind::Variable` — не компилируются).
- [ ] Контроль потока: `for`, `do/while`, `break`, `continue`, `switch`.
- [ ] Доп. операторы: `%`, битовые, составные присваивания (`+=`), `++`/`--`.
- [ ] Квалификаторы `const` и проверка типов при вызове.
- [ ] Реальная обработка `#include` (сейчас только фиксируется) и резолвинг зависимостей `import`.
- [ ] Фильтрация видимости `export` на уровне VM (сейчас VM грузит все функции).
- [ ] Перегрузка функций (сейчас поиск только по имени).

## Этап 2. Байт-код и VM

- [ ] Снять ограничение в 256 констант и 1-байтных операндов (переменная длина операндов, пул `u16/u32`).
- [ ] Снять ограничение `i16` на смещения переходов.
- [ ] Вызовы методов объектов и доступ к полям из байт-кода (`GetField`, `SetField`, `CallMethod`).
- [ ] Диагностика: стек-трейсы, номера строк в ошибках рантайма.
- [ ] Исключения и `try/catch` в скриптах.

## Этап 3. Среда выполнения (`xenon.env`)

- [ ] Реальные встроенные методы `String`/`Vector` (длина, concat, push/pop, итерация) — сейчас модуль только описывает классы.
- [ ] Связывание нативных классов/методов (не только функций через `registerNative`).
- [ ] Доп. классы среды: `Map`, `Array`, обёртки чисел, `Math`.
- [ ] Сборка мусора в `VirtualHeap` (сейчас просто `std::vector` без GC).

## Этап 4. Упаковщик и CLI

- [ ] Сжатие (DEFLATE) вместо STORE в `.xenon`.
- [ ] Расширенный манифест: зависимости, версия рантайма, параметры запуска.
- [ ] Улучшенные сообщения об ошибках и единые коды завершения (sysexits).
- [ ] Проверка целостности/CRC, опционально подпись архива.

## Этап 5. Качество и инфраструктура

- [ ] Больше тестов: крайние случаи парсера, round-trip упаковщика, фазз VM.
- [ ] CI (GitHub Actions) на MSVC/GCC/Clang.
- [ ] `cmake --install` + пакетирование.
- [ ] Оптимизации VM: computed goto, inline caching, constant folding.
- [ ] Формальная спецификация языка в `docs/language.md`.
