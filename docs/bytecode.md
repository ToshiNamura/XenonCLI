# Байт-код и VM

## Набор инструкций

Каждая инструкция — однобайтовый опкод, за которым могут идти операнды.

| Опкод | Операнд | Действие |
| --- | --- | --- |
| `Constant` | u8 индекс | положить константу из пула на стек |
| `LoadLocal` | u8 слот | положить локальную переменную |
| `StoreLocal` | u8 слот | записать вершину стека в локальную |
| `Pop` | — | снять вершину стека |
| `Add` / `Subtract` / `Multiply` / `Divide` | — | бинарные арифметические операции |
| `Negate` / `Not` | — | унарные операции |
| `Equal` / `NotEqual` | — | равенство (любые типы) |
| `Less` / `LessEqual` / `Greater` / `GreaterEqual` | — | сравнение чисел |
| `Jump` | i16 смещение | безусловный относительный переход |
| `JumpIfFalse` | i16 смещение | переход, если вершина ложна |
| `Call` | u8 индекс функции | вызов функции |
| `Return` | — | вернуть вершину стека как результат |

## Модель исполнения

- Стек операндов — внешний, принадлежит `Runtime` (класс `VirtualStack`).
- Каждый вызов функции создаёт **кадр**: указатель на `XenonBinary`, указатель
  инструкции (`ip`), массив локальных слотов.
- Локальные слоты: параметры занимают `0..arity-1`, остальные — локальные переменные.
- `Call` снимает аргументы со стека и заполняет параметры вызываемой функции.
- `Return` снимает кадр и передаёт результат вызывающему; для верхнего кадра —
  кладёт результат в `lastValue`.
- Символ с `Defined = false` (объявление из `.hint`) исполняется как внешний
  вызов: VM ищет нативную реализацию через `registerNative`.

## Символ функции

```cpp
struct Symbol {
    std::string Name;      // имя
    SymbolKind Kind;       // Function, Class, Struct, Enum, Template, Variable
    std::string Signature; // например, "double add(double, double)"
    std::size_t Arity;     // число параметров
    std::size_t Locals;    // число локальных слотов сверх параметров
    bool Defined;          // false — объявление без тела (`.hint`)
    XenonBinary Body;      // бинарный код тела
};
```

## Формат файла `.module`

Бинарный, little-endian.

| Поле | Тип |
| --- | --- |
| магия | `'X' 'E' 'N' 'M'` (4 байта) |
| версия | u32 (= 1) |
| имя модуля | строка (u32 длина + байты) |
| количество импортов | u32 |
| импорты | строки |
| количество символов | u32 |
| на каждый символ | kind (u8), defined (u8), имя, сигнатура, arity (u32), locals (u32), binary |

`XenonBinary` сериализуется как: код (u32 размер + байты), константы (u32 количество + значения),
номера строк (u32 количество + i32).

Значения (`Value`) кодируются тегом:

| Тег | Значение |
| --- | --- |
| 0 | `null` |
| 1 | `bool` |
| 2 | `double` |
| 3 | `Ref` (u32 id) |

Чтение неверных или обрезанных файлов выбрасывает `xenon::ModuleFileError`.

## Упаковка `.xenon`

Файл `.xenon` — ZIP-архив (метод STORE, без сжатия) с манифестом
`META-INF/MANIFEST.MF`. Его создаёт `Packer`.
