# Язык

Xenon-скрипт — модуль, похожий на интерфейсный модуль C++20 (`.ixx`).

## Структура файла

```cpp
export module Example;      // 1) объявление модуля (обязательно, первым)

import Math;                // 2) зависимости (как using/import в C#)
import IO.Core;

#include "xenon/xenon.hpp"  // 3) инклуды хост-окружения

double add(double a, double b) // 4) тело: функции
{
    return a + b;
}
```

Правила заголовка:

| Элемент | Назначение |
| --- | --- |
| `export module Name;` | объявляет имя модуля; обязателен и должен идти первым |
| `import Name;` | зависимость от другого модуля |
| `#include ...` | текстовый инклуд (содержимое вставляется на место директивы) |
| `export` | помечает объявление как видимое снаружи модуля |

`export` проверяется при связывании: функция, метод, тип или глобальная
переменная без `export` доступны только внутри своего модуля. Вызов такого
символа из другого модуля — ошибка времени выполнения
(`'hidden' is not exported by module 'Secret'`). Явный запуск из CLI
(`xenon run <module> <function>`) считается вызовом хоста и разрешён всегда.

## Типы

| Тип | Замечание |
| --- | --- |
| `int`, `double` | числовые; на этапе исполнения хранятся как `double` |
| `bool` | логический |
| `string` | строка; литерал создаёт объект `String` на куче виртуальной машины |
| `void` | только как тип возврата функции |
| `Name`, `Name<Args>` | объявленный класс/структура/перечисление (в том числе шаблонный) |

## Проверка типов

Компилятор выводит тип выражения и проверяет совместимость при:

- инициализации переменной (`double x = "text";` — ошибка);
- присваивании (`s = 1.0;` для `string s` — ошибка);
- присваивании полю (`p.value = "text";` — ошибка);
- вызове функции/метода: арность и типы аргументов
  (`scale("text")` для `double scale(double)` — ошибка);
- `return`: значение должно соответствовать объявленному типу, в `void`-функции
  `return expr;` запрещён, в непустой — `return;` без значения;
- ветвях `?:` — типы должны быть совместимы.

Правила совместимости:

- `int`, `double`, `float`, `long` взаимозаменяемы (все хранятся как `double`);
- `null` присваивается любому нечисловому типу (классу, `string`);
- шаблонные типы сравниваются по базовому имени: `Pair` и `Pair<double>`
  совместимы;
- если тип вывести не удалось (например, для необъявленного символа), проверка
  пропускается — об ошибке сообщит связывание.

Сообщение об ошибке содержит номер строки: `... (line 12)`.

## Квалификатор `const`

`const` запрещает запись после объявления. Поддерживается для локальных и
глобальных переменных, полей и параметров:

```cpp
const double pi = 3.14159;       // глобальная константа

struct Circle
{
	const double radius;         // поле только для чтения
};

double area(const double radius) // параметр только для чтения
{
	const double scale = 2.0;    // локальная константа
	Circle c = new Circle();
	return pi * radius * radius * scale;
}
```

Попытка присвоить значение, применить `++`/`--` или составное присваивание к
`const`-сущности — ошибка компиляции. Локальная `const`-переменная обязана иметь
инициализатор.

## Литералы

- числа: `1`, `2.5`
- `true`, `false`
- `null`
- строки: `"hello"`

## Выражения

Приоритет от низшего к высшему:

| Приоритет | Операторы |
| --- | --- |
| присваивание | `=`, `+=`, `-=`, `*=`, `/=`, `%=`, `&=`, `\|=`, `^=`, `<<=`, `>>=` |
| тернарный | `?:` |
| логическое ИЛИ | `\|\|` |
| логическое И | `&&` |
| побитовое ИЛИ | `\|` |
| побитовое исключающее ИЛИ | `^` |
| побитовое И | `&` |
| равенство | `==`, `!=` |
| сравнение | `<`, `<=`, `>`, `>=` |
| сдвиги | `<<`, `>>` |
| сложение | `+`, `-` |
| умножение | `*`, `/`, `%` |
| унарные | `!`, `~`, `-`, `++`, `--` |
| постфиксные | `x++`, `x--` |
| вызов и доступ | `f(args)`, `obj.field`, `Type::member`, `Name<Args>` |

`&&` и `||` вычисляются с коротким замыканием, `?:` — лениво (вычисляется только
выбранная ветвь). Присваивания правоассоциативны и возвращают записанное
значение.

### Арифметика

| Оператор | Семантика |
| --- | --- |
| `+`, `-`, `*`, `/` | арифметика `double`; деление на ноль — `RuntimeError` |
| `%` | остаток `std::fmod`; деление на ноль — `RuntimeError` |

### Побитовые операции и сдвиги

Числа в Xenon — `double`, поэтому побитовые операторы работают с **целой
частью** значения (усечение к `int64`), а результат снова становится `double`.

| Оператор | Семантика |
| --- | --- |
| `a & b` | побитовое И |
| `a \| b` | побитовое ИЛИ |
| `a ^ b` | побитовое исключающее ИЛИ |
| `~a` | побитовое НЕ |
| `a << n` | сдвиг влево (`n` в диапазоне `0..63`) |
| `a >> n` | арифметический сдвиг вправо (`n` в диапазоне `0..63`) |

Выход значения за диапазон `int64` или сдвиг вне `0..63` — `RuntimeError`.

### Инкремент и декремент

```cpp
double i = 0.0;
double a = i++;   // a = 0, i = 1
double b = ++i;   // b = 2, i = 2
double c = i--;   // c = 2, i = 1
double d = --i;   // d = 0, i = 0
```

Операнд `++`/`--` — переменная (локальная или глобальная) либо поле
(`obj.field++`). Для неприсваиваемого выражения — ошибка компиляции.

### Составные присваивания

```cpp
double x = 10.0;
x += 5.0;   // 15
x %= 4.0;   // 3
x <<= 2.0;  // 12
```

Поддерживаются для переменных и полей (`box.value *= 2.0;`), возвращают новое
значение.

## Операторы

```cpp
double x = 1.0;                    // объявление с инициализацией
x = x + 2.0;                       // присваивание
x += 1.0;                          // составное присваивание
double sign = x > 0.0 ? 1.0 : -1.0; // тернарный оператор
if (x > 2.0) { /* ... */ }
else { /* ... */ }
while (x < 10.0) { /* ... */ }

do { /* ... */ } while (x < 10.0);

for (double i = 0.0; i < 10.0; i++) { /* ... */ }

break;
continue;

switch (x)
{
    case 1.0:
        /* ... */
    default:
        /* ... */
}

return x;
```

## Функции

```cpp
double square(double n)
{
    return n * n;
}

double main()
{
    return square(4.0);
}
```

- Объявление: `тип имя(параметры) { тело }`.
- Вызов: `имя(аргументы)`.
- `main()` — точка входа для CLI.

## Классы и структуры

```cpp
struct Point
{
    double x;
    double y;
};

double main()
{
    Point p = new Point();
    p.x = 3.0;
    p.y = 4.0;
    return p.x + p.y;
}
```

- Объявление: `struct Name { поля; методы; };` (аналогично `class`).
- Поля: `тип имя;` или `тип имя = <константа>;`. Инициализатор применяется при
  создании объекта (`new`); без инициализатора поле равно `null`.
- Методы — статические, вызываются как `Name::method(args)`.
- Конструктор: `new Name()` создаёт объект на куче (аргументы пока не поддерживаются).
- Доступ к полю: `obj.field` (чтение и запись).

## Перечисления

```cpp
enum Color
{
    Red,
    Green,
    Blue,
};
```

Перечислители получают значения `0, 1, 2, ...` в порядке объявления и
доступны как константы:

```cpp
Color favorite = Color::Blue;  // 2
double code = Red;             // 0 — неквалифицированное имя, если оно уникально
```

- Квалифицированная форма `Type::Name` работает всегда.
- Неквалифицированное имя допустимо, только если оно не встречается в других
  перечислениях; иначе — ошибка `ambiguous enumerator`.
- Перечислители совместимы с числовыми типами (хранятся как числа), поэтому
  их можно использовать в `switch`, арифметике и глобальных инициализаторах.

## Глобальные переменные

```cpp
int counter = 0;
const double pi = 3.14159;

double main()
{
    counter = counter + 1;
    return counter * pi;
}
```

- Объявление на верхнем уровне: `тип имя;` или `тип имя = константа;`.
- Опциональный квалификатор `const` (запись проверяется — см. раздел про `const`).
- Инициализатор — константное выражение: число, `bool`, `null`, строка, унарный
  минус, арифметика (`+ - * / %`), побитовые операции, сдвиги и перечислители.
  Строковые константы попадают в пул строк модуля и создаются на куче при
  загрузке.

## Шаблоны

```cpp
template <typename T>
struct Box
{
    T value;
};

template <typename T>
T identity(T x)
{
    return x;
}

double main()
{
    Box<double> b = new Box<double>();
    b.value = identity<double>(5.0);
    return b.value;
}
```

- Объявление: `template <typename T>` (или `class T`) перед функцией или
  `struct`/`class`.
- Инстанцирование явное: `Name<Args...>`.
- Шаблонные функции вызываются как `name<double>(...)`; шаблонные классы —
  `new Box<double>()`.
- Не поддерживаются: шаблонные перечисления, шаблонные глобальные переменные,
  неявный вывод типов (инстанцирование только явное).

## Файлы `.hint`

Файлы `.hint` содержат объявления без реализации (синтаксис как у C++) —
компилятор доверяет им и считает, что символы будут предоставлены на этапе
выполнения:

```cpp
double sqrt(double x);                 // прототип функции
struct Point { double x; double y; };   // объявление структуры
enum Color { Red, Green, Blue };        // объявление перечисления
```

На этапе выполнения хост регистрирует реализации через `Runtime::registerNative`.

## Пока не поддерживается

- встроенные функции;
- фильтрация видимости `export` на уровне VM (парсер учитывает пометку,
  но VM загружает все функции).
